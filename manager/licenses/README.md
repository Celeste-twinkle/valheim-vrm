# Manager loader notices

The Windows manager includes [BepInEx 5.4.23.3 for Windows x64](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.3).
The manager installs the original runtime binaries and configuration from that release. License
texts are embedded in the manager and copied into `BepInEx/core/ValheimVRM-Licenses`
with the loader.

- [BepInEx](https://github.com/BepInEx/BepInEx/tree/v5.4.23.3) and [HarmonyX](https://github.com/BepInEx/HarmonyX)
- [Mono.Cecil](https://github.com/jbevain/cecil) and [MonoMod](https://github.com/MonoMod/MonoMod)
- [UnityDoorstop 4.4.0](https://github.com/NeighTools/UnityDoorstop/tree/v4.4.0)

The client runtime and its notices are documented in [Third-party components](../../docs/THIRD-PARTY-NOTICES.md).
